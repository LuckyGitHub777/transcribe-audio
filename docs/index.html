One simple default

Run Transcribe-Audio.cmd once. After setup, type transcribe-audio. Press Enter for the newest recording.

Local by default

This webpage does not upload or transcribe files. The Windows app processes recordings and transcripts locally.

Honest first run

Setup may download required components, and the first transcription may download the selected Whisper model. Compatible NVIDIA GPUs are used automatically; CPU fallback remains available.
